# 📄 Document Verification System

A Full Stack **Document Verification System** developed using **React.js, Node.js, Express.js, MongoDB Atlas, and JWT Authentication**. This project enables users to upload documents securely while allowing administrators to verify and manage submitted documents.

---

## 🚀 Features

- 👤 User Registration & Login
- 🔐 JWT Authentication & Authorization
- 📂 Secure Document Upload
- 📄 View Uploaded Documents
- ✅ Admin Document Verification
- 👨‍💼 Role-Based Access Control (Admin/User)
- 📱 Responsive User Interface
- ☁️ MongoDB Atlas Integration

---

## 🛠️ Tech Stack

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/chandraprakashy513-cloud/Document-Verification-System.git
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
